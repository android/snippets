Button (All variants)

Buttons allow users to trigger a defined action with a single tap. Material 3 provides five distinct types: Filled, Filled Tonal, Elevated, Outlined, and Text.
Actions

Filled button

Filled buttons have the highest visual impact and are used for the primary, most important action on a screen.
Actions

Filled tonal button

Filled tonal buttons are an alternative middle ground between filled and outlined buttons, offering visual prominence for secondary actions.
Actions

Elevated button

Elevated buttons are high-emphasis buttons with a drop shadow, useful on patterned or complex backgrounds.
Actions

Outlined button

Outlined buttons are medium-emphasis buttons with a stroke outline, used for secondary actions like 'Cancel' or 'Back'.
Actions

Text button

Text buttons have the lowest visual impact and are used for lowest-emphasis actions, dialog dismissals, or inside cards.
